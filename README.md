# ESP Ra.De. graphics catalog

Browse the current sprite, animation, screen-art and background reconstruction at
https://coldnightwarmth.github.io/esprade/.

Use **Inspect** to view native frames and recovered sequences. The download icon
exports a single frame as PNG or an animation as a looping GIF. Multiple selected
states are packaged in a ZIP. All states start selected; All, None, and dragging
across checkboxes make selection quick.

This is a work-in-progress reconstruction catalog, not a claim of complete game
coverage. Graphics remain at native pixel resolution. GIF timing is rounded to
centiseconds; GIFs allow at most 256 colors per frame. The original PNGs remain
available in the inspector. Game artwork belongs to its respective rights holders.

This repository contains the current static publication. Exact duplicate image
files share a content-addressed path. ROM archives and local research manifests
are not part of the site. GIF encoding uses gifenc 1.0.3 (MIT; license in `vendor/`).
